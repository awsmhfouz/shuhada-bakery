# دفتر مخبز الشهداء

تطبيق موبايل بسيط لحسابات المخبز. بيشتغل على أندرويد وآيفون من المتصفح، وبينثبت على الشاشة الرئيسية، وبيشتغل بدون إنترنت.

**رابط التطبيق:** https://awsmhfouz.github.io/shuhada-bakery/

## شو فيه

- **بيع الخبز:** بالربطة (السعر الافتراضي ٥ ₪)، نقدي أو على حساب زبون.
- **فاتورة لكل بيعة:** رقم متسلسل وتاريخ وساعة، وبتطلع PDF أو صورة تبعتها للزبون على واتساب.
- **ذمم الزباين:** رصيد افتتاحي، ومبيعات آجلة، وقبض دفعات، وكشف حساب.
- **العمال:** اليومية ورصيد افتتاحي، وتسجيل أيام الشغل، والدفعات والسلف، وكشف حساب.
- **التقارير:** يومي وأسبوعي وشهري أو أي فترة بتحددها.
- **نسخة احتياطية:** تنزيل واسترجاع ملف JSON.

## التثبيت على التلفون

- **آيفون (Safari):** افتح الرابط، اضغط زر المشاركة، واختار «إضافة إلى الشاشة الرئيسية».
- **أندرويد (Chrome):** افتح الرابط، ومن القائمة ⋮ اختار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## وين بتنحفظ البيانات

البيانات بتنحفظ على التلفون نفسه بس، وما بتطلع على GitHub ولا على أي سيرفر. عشان هيك:

- خذ **نسخة احتياطية** من الإعدادات كل أسبوع، وابعتها لحالك على واتساب أو احفظها بالدرايف.
- لما تغيّر التلفون، افتح التطبيق على التلفون الجديد واسترجع آخر نسخة.
- مسح بيانات المتصفح أو حذف التطبيق بيمسح الدفتر، فلازم تكون عندك نسخة قبل ما تعمل هيك.
